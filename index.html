Go Mobile Indonesia · LinkedIn carousel · Designer brief v1

UA attribution fraud case study
— 9 slides, visual-led

Wireframes below are proportion and device references, not final art. Brand styling (gradients, sparkle texture, wordmark, type) stays as per the existing Go Mobile carousel system. What's fixed here is the device on each slide, the copy, and the colour meaning.

The angle

Not the bot-farm story. The traffic was real. The installs were real. Only the credit was fake. Someone was billing for users who were already installing.

Canvas

1080 × 1350 px, 9 slides. Safe margin 80 px all sides.

Copy ceiling

Max ~20 words per slide. If a slide needs a paragraph, the device is wrong.

Thumbnail test

Slide 1 must read at 400 px wide on a phone feed. No body copy on it.

Caveats

All disclaimers (anonymised, client platform, proprietary method) move to the caption. None on slides.

Grey = normal / unproven supply Red = contaminated Green = proven / genuine Orange = Go Mobile intervention

Colour is information in this set, not decoration. Nothing else gets a colour — no blue, no magenta, no rainbow stat cards.

05 — The gate / filter
Slide 05 · The solution

The gate

Copy 14 words
We stopped blocking what fails. We buy only what passes.Footer: Nothing enters the main buy until it has proven itself.
Device

Mixed supply enters from the left → passes through an orange Daily check gate → exits into two lanes: a wide green PROVEN / FULL BUDGET lane and a narrow grey UNPROVEN / CAPPED lane.

Designer notes
  • Lane width carries the budget split — the green lane is visibly wider. Don't equalise them for tidiness.
  • Orange appears here for the first time in the set. That's deliberate: orange = us, and this is the slide where we act.
  • No mention of thresholds or test logic. Method stays proprietary.

The bookend

Copy 14 words
22.2% → 0.96% in three weeks.Footer: Same audit runs on any account with raw attribution data. · CTA: Talk to us.
Device

The identical 100-dot grid from slide 1, same position, same size — now with a single red dot. Nothing else on the slide.

Designer notes
  • Protect this one. It's the cheapest element in the set to build and the only one that closes the story visually. Grid position and dot size must match slide 1 exactly, so a viewer swiping back feels the difference.
  • Leave the last red dot in a different position from any red dot on slide 1 — one survivor, not a leftover.

Production notes

  1. Existing Go Mobile brand system stays: sparkle background texture, wordmark placement, rounded-card language, heavy geometric display face. What changes is that each slide now carries a drawn device instead of a coloured text card.
  2. Retire the multi-colour stat stickers from the current version. Every colour in this set means something specific (see legend).
  3. Slides 1 and 9 share one asset — build the dot grid once, change the red indices.
  4. Deliver 1080 × 1350 PNG ×9. Also export slide 1 alone at 1200 × 627 for the link-preview / repost variant.
  5. Caption carries: methodology disclaimer, anonymisation note, the 1.7% organic band detail, and the CTA. Slides carry none of it.
